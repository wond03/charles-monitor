========================================
查尔斯信号监控系统 · 手机版部署说明
========================================

【这个包里有什么】
- config.yaml / datafeed.py / monitor.py / pusher.py / signal_engine.py / test_signal.py / requirements.txt / README.md
  → 这8个文件直接上传到 GitHub 仓库
- 1_手动创建文件_monitor.yml.txt
  → 里面是定时任务文件的内容（因为 .github 是隐藏文件夹，手机上选不到，改用网页手动创建）

【步骤一】上传8个普通文件
1. 手机浏览器打开：https://github.com/wond03/charles-monitor
2. 点 Add file → Upload files
3. 全选这8个文件（不含"0_先读我"和"1_手动创建"两个txt）：
   config.yaml、datafeed.py、monitor.py、pusher.py、signal_engine.py、test_signal.py、requirements.txt、README.md
4. 点 Commit changes

【步骤二】手动创建定时任务文件
1. 回到仓库主页，点 Add file → Create new file
2. 文件名输入框填：.github/workflows/monitor.yml
   （输入后会自动创建 .github 和 workflows 文件夹）
3. 打开手机上的"1_手动创建文件_monitor.yml.txt"，全选复制全部内容
4. 粘贴到网页的大文本框里
5. 点 Commit changes

【步骤三】配置企业微信密钥
1. 仓库 Settings → Secrets and variables → Actions
2. 点 New repository secret
3. Name 填：WECOM_WEBHOOK
4. Secret 填：https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=9dfe55d7-466f-4a34-b5dd-5d86e7251b24
5. 点 Add secret

【步骤四】测试
1. 手机浏览器打开：https://github.com/wond03/charles-monitor/actions
2. 左侧点 charles-monitor 工作流
3. 点 Run workflow → 分支选 main → 确认
4. 等1-2分钟，绿色勾=成功，企业微信收到推送

【完成后】
系统每15分钟自动扫一次 BTC / 黄金(永续合约)，命中信号推送企业微信，无需再管。

【备注】
仓库现在是 Public(公开)，Actions 免费额度不限，无需改。
那个之前误传的 prod_ 开头的杂文件，可以在仓库文件列表里点开 → 垃圾桶图标删除，不影响系统。
